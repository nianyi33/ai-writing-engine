# 风险评估

## 技术风险

### 高

| 风险 | 说明 | 缓解 |
|------|------|------|
| AI 输出不稳定 | 同 prompt 多次输出质量波动大 | 低 Temperature(0.3-0.5) + 重试机制 + 输出校验 |
| 长文本上下文超限 | 小说轻松超过 64K tokens | 分块注入 + 摘要压缩 + Token 计数器前端展示 |

### 中

| 风险 | 说明 | 缓解 |
|------|------|------|
| IndexedDB 性能 | 大量版本快照可能拖慢 | LRU 清理 + 快照压缩 + 存储配额监控 |
| 编辑器性能 | 10万字+文档渲染 | CodeMirror 虚拟滚动 + 分章节加载 |
| API 费用 | 长篇每次续写消耗 tokens 高 | 用量统计面板 + 费用估算 + 本地模型 fallback |

### 低

| 风险 | 说明 | 缓解 |
|------|------|------|
| 浏览器存储配额 | IndexedDB 有上限 | 提示用户清理 + 未来迁移到文件系统 |
| 跨浏览器兼容 | Safari 对某些 API 支持差 | 渐进增强 + 降级方案 |

## 产品风险

| 风险 | 说明 | 缓解 |
|------|------|------|
| 对标 MuseAI 缺乏差异化 | 纯复刻没有竞争力 | 强调"游戏素材生成"差异化：AI写作 → AI生成游戏角色 |
| AI 写作质量达不到预期 | 网文作者对质量要求高 | 聚焦"辅助"而非"替代"，强调人机协作 |
| 用户习惯 Notion/飞书等 | 切换成本高 | 提供导入功能 + 导出为标准格式 |

## 进度风险

| 风险 | 说明 | 缓解 |
|------|------|------|
| Agent 单线程瓶颈 | 复杂任务排队等待 | 并行调度 + 独立子任务 |
| 前端后端联调阻塞 | 接口定义不明确 | 先定接口契约再并行开发 |
