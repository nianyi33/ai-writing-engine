# 实施路线图

```
Week 1: 基建 + AI核心
  Day 1-2: Phase 1 — 需求梳理 + 架构设计
  Day 3-5: Phase 2 — 项目骨架 + 编辑器 + 存储层 + PWA

## Phase 5：UI/UX 打磨 + Tauri 打包（Day 12-14）

### 调用 Agent

```
UX Architect → UI Designer → Frontend Developer
         │
         └──→ 前端 PWA 配置就绪
                    │
                    ▼
              Tauri 2 集成 + 打包

### UI/UX 任务
1. 暗色主题（写作者友好）
2. 编辑器字体/行高/间距调优
3. 侧栏布局优化
4. 空状态页面（新用户引导）
5. 加载/错误状态处理

### PWA 配置任务
1. `manifest.json` + Service Worker 注册
2. `vite-plugin-pwa` 集成
3. 离线缓存策略配置
4. 桌面安装验证

### Tauri 打包任务（并行）
1. 安装 Tauri CLI + Rust 工具链
2. 初始化 `src-tauri/`
3. 配置窗口、权限、图标
4. `npx tauri build` 生成安装包
5. Windows .exe / macOS .dmg 验证

## 风险缓解

| 风险 | 概率 | 缓解方案 |
|------|------|---------|
| AI 输出不稳定导致体验差 | 高 | 重试机制 + 降级提示 + Temperature 锁定 |
| 长文本上下文超限 | 中 | 分块 + 摘要压缩 + Token 预算告警 |
| IndexedDB 文件体积膨胀 | 低 | LRU 清理 + 存储配额监控 |
| API 费用超预期 | 低 | 本地模型 fallback + 用量统计面板 |
