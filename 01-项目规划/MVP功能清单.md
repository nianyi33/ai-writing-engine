# MVP 功能清单

## 为什么是这些功能

对照 MuseAI（202 stars，172 个功能点），我们截取 **用户打开应用前 10 分钟内会用到的功能** 作为 MVP。按"能写出第一个章节"为最低闭环标准。

---

## P0：必须交付（第一个可用版本）

### 1. 作品管理

| 需求 | 详情 |
|------|------|
| 创建/删除/重命名作品 | 一个作品 = 一个目录 |
| Markdown 编辑器 | CodeMirror 6 + 实时预览 |
| 自动保存 | 30秒节流 + 失焦保存 |
| 版本历史 | AI 修改前自动存快照，支持回退 |
| 作品列表 | 首页卡片网格，显示标题 + 字数 + 最后修改时间 |

### 2. AI 续写

| 需求 | 详情 |
|------|------|
| 内联续写 | 光标位置提示 AI 接着写 |
| 流式输出 | SSE，实时看到 AI 打字 |
| 上下文注入 | 自动携带当前章节前文 + 大纲设定 |
| 接受/拒绝 | AI 生成后插入/丢弃 |
| 重试 | 同一个提示重新生成 |

### 3. 模型配置

| 需求 | 详情 |
|------|------|
| API Key 管理 | 本地加密存储，支持多Key |
| 模型选择 | 下拉选择模型（DeepSeek / Claude / GPT 等） |
| 参数调节 | Temperature、Max Tokens |
| 场景绑定 | 不同场景（续写/分析/去味）可绑定不同模型 |

---

## P1：第二版交付

### 4. 大纲分析

| 需求 | 详情 |
|------|------|
| 大纲编辑器 | 结构化输入（卷/章/节） |
| AI 分析评分 | 评估完整性、节奏、冲突密度 |
| 雷达图展示 | ECharts 可视化各维度得分 |
| 一键生成大纲 | 从一句话梗概展开完整章纲 |
| 大纲 ↔ 正文对照 | 写作时侧栏显示当前章节大纲 |

### 5. 去 AI 味

| 需求 | 详情 |
|------|------|
| 一键检测 | 扫描选中文本，标记疑似 AI 腔片段 |
| AI 重写 | 保留原意，改写为更自然的文风 |
| 前后对比 | Diff 视图展示修改变化 |
| 自定义风格 | 可配置目标文风（网文化/轻小说/严肃文学） |

---

## P2：第三版交付

### 6. 角色伴侣

| 需求 | 详情 |
|------|------|
| 角色卡片 | 创建角色（姓名、性格、说话风格、背景） |
| 世界设定 | 世界观文档，AI 自动提取要素 |
| 角色对话 | 选择角色，与其聊天（角色扮演模式） |
| 对话提取灵感 | 与角色聊天中捕获可用情节 |

### 7. 情缘系统

| 需求 | 详情 |
|------|------|
| 关系值 | AI 追踪主角与各角色好感度 |
| 互动记录 | 对话历史中的关键事件自动存档 |
| 关系变化曲线 | 可视化展示关系随章节推进的变化 |

### 8. 反向大纲

| 需求 | 详情 |
|------|------|
| 输入片段分析 | 粘贴已完成小说片段，AI 提取大纲结构 |
| 情节密度图 | 可视化各章节事件密度 |

### 9. 文件导入导出（⭐ PM评审升为P1）

| 需求 | 详情 |
|------|------|
| 导入 .md 小说 | 拖入/选择 .md 文件，自动解析章节结构（按 # 标题或 --- 分隔） |
| 导出 .md | 导出当前章节或全书为 .md 文件 |
| 导出 .txt | 纯文本导出（去Markdown标记） |

### 10. 分支结局（⭐ PM评审升为P1）

| 需求 | 详情 |
|------|------|
| 导入整本小说 | 拖入 .md 文件，自动解析章节结构 |
| 标记分叉点 | 在章节树中选择分叉位置，创建分支 |
| AI 生成分支大纲 | 输入"想要什么样的结局"，AI 生成分支大纲 |
| 分支内续写 | 在分支中逐章续写，AI 保持与原作前文一致 |
| 多分支管理 | 命名、切换、对比不同结局版本 |
| 分支树可视化 | 像 Git 分支图一样看到故事的版本树 |
| 导出 | 导出单个分支的完整小说 |

> 详见 [分支结局功能设计](../02-架构设计/分支结局功能设计.md)
