# Agent 协作链定义

## 链 1：新功能开发（主链）

```
Product Manager（梳理需求，对齐范围）
    │
    ▼
Software Architect（技术选型 + 架构设计）
    │
    ├─────────────────────────────────────┐
    ▼                                     ▼
Frontend Developer               Backend Architect
(页面组件 + 路由 + 状态)         (API + 存储 + 版本系统)
    │                                     │
    └───────────────┬─────────────────────┘
                    ▼
              Code Reviewer（审查接口对接 + 代码质量）
                    │
                    ▼
              Frontend Developer（功能串联整合）
                    │
                    ▼
              Code Reviewer（第二轮审查）
                    │
                    ▼
              Reality Checker（全流程验证）
                    │
                    ▼
              Security Architect（安全审计）
```

## 链 2：AI 功能开发（子链）

```
Prompt Engineer（编写/调优 System Prompt）
    │
    ├─ 并行 ──────────────────────────┐
    ▼                                 ▼
AI Engineer                        Reality Checker
(多模型路由 + 流式)                (测试生成效果)
    │                                 │
    └───────────────┬─────────────────┘
                    ▼
              Prompt Engineer（根据测试结果迭代 Prompt）
                    │
                    ▼
              AI Engineer（联调流式输出 + 异常处理）
```

## 链 3：UI/UX 改造（子链）

```
UX Architect（信息架构 + 操作流程）
    │
    ▼
UI Designer（视觉设计 + 组件样式）
    │
    ▼
Frontend Developer（实现 UI）
    │
    ▼
Brand Guardian（一致性检查）
    │
    ▼
Accessibility Auditor（无障碍合规）
```

## 链 4：Bug 修复

```
Reality Checker（复现 + 定位根因）
    │
    ▼
Senior Developer（修复 + 单元测试）
    │
    ▼
Code Reviewer（确认无副作用）
```

## 链 5：性能优化

```
Performance Benchmarker（检测瓶颈）
    │
    ▼
Senior Developer（优化实现）
    │
    ▼
Performance Benchmarker（对比验证）
    │
    ▼
Code Reviewer（确认无退化）
```

---

## 并行调度规则

当两个 Agent 的任务独立时，**同时启动**：

```typescript
// 例：Phase 2 基建阶段
parallel([
  () => agent('frontend-developer', '搭建页面路由 + 编辑器组件'),
  () => agent('backend-architect', '搭建 API 路由 + 存储层'),
])
// 两个 Agent 同时工作，互不阻塞
```

当存在依赖时，**串行等待**：

```typescript
// 例：Phase 1 需求→架构
const requirements = await agent('product-manager', '梳理 MVP 功能清单')
const architecture = await agent('software-architect', `基于需求方案 ${requirements} 设计架构`)
// Product Manager 的输出作为 Software Architect 的输入
```
