# UI 设计规范

## 设计理念

- **沉浸式** — 写作时界面不干扰思路，减少视觉噪音
- **专业感** — 暗色主题为主，类似 VS Code / Obsidian 的感觉
- **效率优先** — 高频操作放在触手可及的位置

## 色彩系统（暗色主题）

```
背景层级：
  主背景:     #1a1a2e    ← 编辑器区域
  次背景:     #16213e    ← 侧栏/面板
  卡片:       #0f3460    ← 卡片/弹窗
  悬停:       #1a4a7a    ← hover 状态

文本层级：
  正文:       #e0e0e0    ← 编辑器正文
  标题:       #ffffff    ← 各级标题
  次要:       #a0a0b0    ← 辅助信息
  禁用:       #606070    ← 禁用态

强调色：
  主色:       #e94560    ← 按钮/链接/选中
  成功:       #27ae60    ← 保存成功
  警告:       #f39c12    ← 未保存
  错误:       #e74c3c    ← 错误状态

代码/编辑器：
  行号:       #505060
  光标:       #528bff
  选区:       rgba(82, 139, 255, 0.3)
```

## 排版

| 用途 | 字体 | 字号 | 行高 |
|------|------|------|------|
| 编辑器正文 | `'Source Han Serif SC', 'Noto Serif CJK SC', serif` | 16px | 1.8 |
| UI 文字 | `'PingFang SC', 'Microsoft YaHei', sans-serif` | 14px | 1.5 |
| 标题 | 同上 | 18-24px | 1.4 |
| 代码 | `'Cascadia Code', 'Fira Code', monospace` | 13px | 1.4 |

## 组件设计原则

1. **可收起** — 侧栏、AI 面板、预览面板均可一键收起，最大化编辑区域
2. **快捷键优先** — `Ctrl+S` 保存、`Ctrl+K` 打开 AI 面板、`Ctrl+` 放大字号
3. **即时反馈** — 保存状态实时显示（底栏状态指示器）
4. **无干扰** — AI 流式输出不弹出模态框，在侧栏静默显示
5. **空状态** — 每个列表/面板都有引导性的空状态提示

## 间距系统

使用 Tailwind 默认间距（4px 递增）：
- 组件内间距：`p-3` (12px) ~ `p-4` (16px)
- 面板间距：`gap-4` (16px)
- 页面边距：`p-6` (24px)

## 图标

使用 `@ant-design/icons` 6.x 图标库。
