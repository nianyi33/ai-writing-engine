# 组件树

## 顶级结构

```
<App>
  <BrowserRouter>
    <AppShell>
      <TopBar />                    ← 顶栏：Logo + 作品选择 + 导航 + 设置入口
      <Sidebar />                   ← 侧栏：章节树 + 大纲快览
      <main>
        <Outlet />                  ← 路由出口，渲染子页面
      </main>
      <StatusBar />                 ← 底栏：字数 + 版本号 + 保存状态
    </AppShell>
  </BrowserRouter>
</App>
```

## 页面组件拆解

### Home.tsx — 首页
```
<Home>
  <WelcomeBanner />                ← 新用户引导
  <WorkCardGrid>                   ← 作品卡片网格
    <WorkCard />                   ← 单张卡片（封面+标题+字数+时间）
    <CreateWorkCard />             ← 新建作品的 "+" 卡片
  </WorkCardGrid>
  <ImportWorkDialog />             ← 导入本地文件对话框
</Home>
```

### Editor.tsx — 主编辑器（核心页面）
```
<Editor>
  <ChapterTree />                  ← 侧栏章节列表
  <div class="editor-pane">
    <MarkdownEditor />             ← CodeMirror 6 编辑器
    <WordCount />                  ← 实时字数
    <MarkdownPreview />            ← 实时预览（可切换显示/隐藏）
  </div>
  <AiSidebar>                      ← AI 功能侧栏（可收起）
    <TabBar: 续写 | 去味 | 分析>   ← 功能切换
    <AiChat>                       ← AI 对话面板
      <AiStreamRenderer />         ← 流式文本渲染
      <AiInput />                  ← 用户指令输入
    </AiChat>
    <VersionHistory>               ← 版本历史面板
      <VersionItem />
      <VersionDiff />
    </VersionHistory>
  </AiSidebar>
</Editor>
```

### Outline.tsx — 大纲页
```
<Outline>
  <OutlineTree />                  ← 树形大纲编辑器
  <OutlineNodeEditor />            ← 选中节点的详情编辑
  <div class="ai-panel">
    <OutlineAssessmentAgentChat /> ← AI 大纲分析对话
    <ScoreRadarChart />            ← 五维评分雷达图
    <OutlineCreationAgentChat />   ← 一键生成大纲
    <ReverseOutlineAnalysisModal />← 反向大纲分析
  </div>
</Outline>
```

### Roles.tsx — 角色页
```
<Roles>
  <RoleCardGrid>
    <RoleCard />                   ← 单张角色卡片
    <CreateRoleCard />             ← 新建角色
  </RoleCardGrid>
  <RoleEditor />                   ← 角色详情编辑面板
</Roles>
```

### RoleChat.tsx — 角色对话页
```
<RoleChat>
  <RoleChatHeader>                 ← 角色信息 + 情缘值
    <RoleInfo />
    <BondBadge />
  </RoleChatHeader>
  <ChatMessages>                   ← 对话气泡列表
    <ChatBubble type="role|user" />
  </ChatMessages>
  <ChatInput />                    ← 消息输入框
</RoleChat>
```

### Bond.tsx — 情缘页
```
<Bond>
  <BondCharacterList />            ← 角色列表（按好感度排序）
  <BondGraph />                    ← 好感度变化折线图
  <BondTimeline>                   ← 关键事件时间线
    <BondEventItem />
  </BondTimeline>
</Bond>
```

### Settings.tsx — 设置页
```
<Settings>
  <SettingsNav />                  ← 设置导航
  <SettingsSection label="模型配置">
    <ModelConfigForm>              ← 模型选择 + 参数
      <PartnerChatSettingsModal /> ← 场景绑定
    </ModelConfigForm>
  </SettingsSection>
  <SettingsSection label="API Key">
    <ApiKeyForm />                 ← Key 管理
  </SettingsSection>
  <SettingsSection label="写作偏好">
    <WritingStyleForm />           ← 文风/人称/字体等
  </SettingsSection>
  <SettingsSection label="主题">
    <ThemeSwitcher />              ← 暗色/亮色切换
  </SettingsSection>
</Settings>
```

### Stats.tsx — 统计页
```
<Stats>
  <DailyWordCount />               ← 每日字数柱状图
  <WritingTimeDistribution />      ← 写作时段热力图
  <ProgressBar />                  ← 全书进度
  <StreakTracker />                ← 连续写作天数
</Stats>
```

| `ScoreRadarChart` | ECharts 雷达图 |
