# 页面路由设计

## 路由表

| 路径 | 页面 | 说明 |
|------|------|------|
| `/` | `Home.tsx` | 首页：作品列表 + 快捷入口 |
| `/work/:workId` | `Editor.tsx` | 主编辑器：Markdown 编辑 + AI 侧栏 |
| `/work/:workId/outline` | `Outline.tsx` | 大纲编辑器 + AI 分析 |
| `/work/:workId/characters` | `Roles.tsx` | 角色卡片管理 |
| `/work/:workId/characters/:charId/chat` | `RoleChat.tsx` | 角色对话 |
| `/work/:workId/bonds` | `Bond.tsx` | 情缘面板 |
| `/work/:workId/stats` | `Stats.tsx` | 写作统计 |
| `/settings` | `Settings.tsx` | 全局设置 |

## 路由守卫

```
AppShell (全局布局)
├── 不需要 workId 的路由
│   ├── / → Home
│   └── /settings → Settings
│
└── 需要 workId 的路由
    ├── /work/:workId → Editor (默认 tab)
    ├── /work/:workId/outline → Outline
    ├── /work/:workId/characters → Roles
    ├── /work/:workId/characters/:charId/chat → RoleChat
    ├── /work/:workId/bonds → Bond
    └── /work/:workId/stats → Stats
```

## 移动端适配

当屏幕宽度 < 768px 时：
- 侧栏收起到汉堡菜单
- 编辑器/预览切换为 Tab 模式
- AI 面板变为底部抽屉
- 路由平铺，不嵌套侧栏
