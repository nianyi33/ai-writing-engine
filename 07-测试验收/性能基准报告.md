> 分析人：Performance Benchmarker
> 日期：2026-06-08
> 方法：代码静态分析（无浏览器运行时可用）

## 核心性能指标评估

### 1. 编辑器性能

| 指标 | 架构保障 | 预估 | 状态 |
|------|---------|------|------|
| 10万字输入延迟 | CodeMirror 6 虚拟滚动 | < 50ms | ✅ |
| 粘贴大段文本 | ViewPlugin 增量更新 | < 100ms | ✅ |
| 实时预览渲染 | react-markdown + 节流 | < 200ms | ✅ |
| Markdown 语法高亮增量 | CM6 增量解析 | < 16ms (60fps) | ✅ |

### 2. IndexedDB 存储性能

| 指标 | 当前实现 | 问题 | 建议 |
|------|---------|------|------|
| 单次写入 | `db.put()` 异步 | ✅ 不阻塞 UI | - |
| 自动保存频率 | 30s 定时器 | ⚠️ 无 debounce | 改为"停止输入 2s 后保存" |
| 版本快照体积 | 完整内容存储 | ⚠️ 50章×50快照≈25MB | 后续考虑 gzip |
| 章节查询 | `db.getAll('chapters')` 全量过滤 | ⚠️ 无索引 | 建 `workId` 索引 |
| 批量写入 | 逐条 `put()` | ⚠️ 导入时串行 | 改用 `db.putAll()` 事务批量 |

### 3. AI 流式输出

| 指标 | 当前实现 | 状态 |
|------|---------|------|
| 首 Token 延迟 | SSE 直连 DeepSeek | ⭐⭐⭐⭐ 预期 < 500ms |
| 流式中断恢复 | 无自动重连 UI 提示 | ⚠️ 建议加 |
| Token 预算告警 | `token-counter.ts` 实时计算 | ✅ 已实现 |

### 4. 内存

| 场景 | 风险 | 预估 |
|------|------|------|
| 10 章节全部加载 | 每章按需加载（`loadChapter`） | ✅ 低风险 |
| 50+ 版本快照渲染 | Timeline 只展示最近 30 条 | ✅ 低风险 |
| 长时间 AI 流式 | 单变量累积 `fullContent` | ⚠️ 10万字流式可能撑爆内存—建议设 max 4096 tokens |

### 5. 构建产物

| 指标 | 实测值 | 评价 |
|------|--------|------|
| JS Bundle | 2.2 MB (gzip: 701 KB) | ⚠️ 偏大（AntD + CodeMirror 占大头） |
| CSS | 12.6 KB (gzip: 3.1 KB) | ✅ |
| PWA 预缓存 | 5 个文件 / 2.2 MB | ✅ |
