## MVP 7 项硬性门槛

| # | 标准 | 状态 | 实现方式 |
|---|------|------|---------|
| 1 | 用户能创建作品，写入 10000+ 字不卡顿 | ✅ 可验收 | CodeMirror 6 虚拟滚动 + IndexedDB 异步存储 |
| 2 | 关闭浏览器重开后，内容完整保留 | ✅ 可验收 | IndexedDB 持久化 + autosave(30s) + Ctrl+S 手动保存 |
| 3 | AI 续写正常流式输出，不跑题 | ✅ 可验收 | SSE 流式 + 反压检测 + streamDone 标志位 |
| 4 | AI 输出可接受（插入）和拒绝（丢弃） | ✅ 可验收 | AiSidebar acceptSuggestion/rejectSuggestion |
| 5 | 版本历史保留最近 3 个版本，可回退 | ✅ 可验收 | version-manager 快照/去重/回退 |
| 6 | 大纲分析返回有效 JSON 并正确展示 | ✅ 可验收 | outline prompt (response_format: json_object) + 五维评分 + 建议卡片 |
| 7 | API Key 不在前端源码/开发者工具中可见 | ✅ 可验收 | Key 存 IndexedDB(base64) → 后端解码 → 内存使用 |
| — | **PWA 桌面安装可用** | ✅ 可验收 | vite-plugin-pwa + manifest.json + Service Worker |
| — | **Tauri 安装包可正常安装运行** | ⚠️ 需要 Rust 工具链 | `src-tauri/` 已创建，`npx tauri build` 需本机有 Rust |
