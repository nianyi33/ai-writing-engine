# 验收标准

## MVP 验收门槛

以下 **7 项全部通过** 才算 MVP 达标：

| # | 标准 | 验证方法 |
|---|------|---------|
| 1 | 用户能创建作品，写入 10000+ 字不卡顿 | 实际输入 1 万字，监控帧率 |
| 2 | 关闭浏览器重开后，之前写的内容完整保留 | 写 500 字 → 关标签页 → 重新打开 |
| 3 | AI 续写能正常流式输出，且内容不跑题 | 输入带角色设定的前文，检查 AI 输出 |
| 4 | AI 输出可被接受（插入编辑器）和拒绝（丢弃） | 点击接受/拒绝按钮 |
| 5 | 版本历史至少保留最近 3 个版本，可回退 | 触发 3 次 AI 修改，检查版本列表 |
| 6 | 大纲分析返回有效的 JSON 并正确展示 | 输入大纲，检查雷达图 |
| 7 | API Key 不在前端源码/开发者工具中可见 | 查看 Network 面板和本地存储 |

## 各 Phase 验收标准

### Phase 2 验收（基建）

- [ ] `npm run dev` 正常启动，无编译错误
- [ ] 所有路由可访问，无 404
- [ ] 创建/删除/重命名作品功能正常
- [ ] Markdown 编辑器可用（CodeMirror 6 加载正常）
- [ ] 自动保存和手动保存均触发
- [ ] IndexedDB 中的数据在页面刷新后不丢失

### Phase 3 验收（AI 核心）

- [ ] 所有 6 套 Prompt 可在 DeepSeek API 上正常运行
- [ ] SSE 流式输出正常，不中断不丢失
- [ ] 多模型切换不报错
- [ ] 上下文不超限（8000 字以内不截断）
- [ ] AI 输出格式符合预期（JSON 可正确解析）

### Phase 4 验收（功能串联）

- [ ] 大纲编辑器可正常 CRUD
- [ ] 大纲分析返回正确评分
- [ ] 角色卡片可创建/编辑/删除
- [ ] 角色对话流畅，角色"不出戏"
- [ ] 设置页配置项生效

### Phase 5 验收（UI/UX）

- [ ] 暗色主题无颜色异常（文字不"消失"）
- [ ] 编辑器字体、行高舒适
- [ ] 侧栏可正常收起/展开
- [ ] 移动端布局不崩

### Phase 6 验收（最终）

- [ ] Code Reviewer 无 P0 问题
- [ ] Reality Checker 全流程走通
- [ ] Security Architect 无高危漏洞
- [ ] 至少完成 1 篇 5000 字的完整写作流程
