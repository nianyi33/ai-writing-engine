# 本地存储方案

## 三层存储架构

```
┌─────────────────────────────────────────┐
│ Layer 1: IndexedDB (主力存储)            │
│ - Docker: ai-writing-engine              │
│ - Stores: works, chapters, versions,     │
│           outlines, characters, bonds,    │
│           conversations, settings, stats  │
│ - 容量: 浏览器限制 (通常 > 100MB)         │
│ - 速度: 极快 (异步，不阻塞 UI)           │
└─────────────────────────────────────────┘
                    ↕ 定期同步
┌─────────────────────────────────────────┐
│ Layer 2: 本地文件系统 (备份 + 导出)      │
│ - 路径: ~/Documents/AI写作引擎/          │
│ - 格式: JSON + Markdown                  │
│ - 用途: 导入/导出 + 灾难恢复             │
│ - API: File System Access API            │
└─────────────────────────────────────────┘
                    ↕ 可选同步
┌─────────────────────────────────────────┐
│ Layer 3: 云端 (Phase 4)                 │
│ - Supabase Storage                       │
│ - 用途: 多设备同步                       │
│ - MVP 阶段不实现                         │
└─────────────────────────────────────────┘
```

## IndexedDB Schema 升级策略

```typescript
const DB_NAME = 'ai-writing-engine';
const DB_VERSION = 2;   // 每次 Schema 变更 +1（v2: versions store 新增 chapterId 索引）

// 版本升级处理
const migrations = {
  1: (db) => {
    // 初始创建所有 stores
    db.createObjectStore('works', { keyPath: 'id' });
    db.createObjectStore('chapters', { keyPath: 'id' });
    db.createObjectStore('versions', { keyPath: 'id' });
    db.createObjectStore('outlines', { keyPath: 'id' });
    db.createObjectStore('characters', { keyPath: 'id' });
    db.createObjectStore('bonds', { keyPath: 'id' });
    db.createObjectStore('conversations', { keyPath: 'id' });
    db.createObjectStore('settings', { keyPath: 'id' });
    db.createObjectStore('stats', { keyPath: 'id' });
  }
};
```

## 存储配额监控

```typescript
// 监控 IndexedDB 使用量
async function getStorageUsage(): Promise<{ used: number; quota: number }> {
  const estimate = await navigator.storage.estimate();
  return {
    used: estimate.usage || 0,
    quota: estimate.quota || 0
  };
}

// 当使用量超过 80% 时告警
// 当超过 90% 时自动清理最旧版本快照
```

## 备份策略

1. **自动备份**: 每天首次打开应用时，自动导出所有数据到本地文件
2. **手动备份**: 设置页的"导出全部数据"按钮
3. **增量备份**: 只备份自上次备份后变更的内容（按 `updatedAt` 判断）

## 版本快照清理

```
保留策略：
  - 最近 10 个版本：全部保留
  - 10-30 个版本：每 5 个保留 1 个（稀疏化）
  - 30 个以上：只保留最早、最新和每 10 个 1 个
  - 总上限：最多保留 50 个快照
```
