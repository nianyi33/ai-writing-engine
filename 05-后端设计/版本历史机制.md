# 版本历史机制

## 触发时机

| 触发事件 | 版本类型 | 说明 |
|---------|---------|------|
| AI 修改前 | `ai_before_modify` | 接受 AI 建议时，保存修改前的内容 |
| 手动保存 (Ctrl+S) | `manual` | 用户主动保存时 |
| 自动保存 (30秒节流) | `auto_save` | 定时器触发，不重复保存未变更内容 |
| 删除章节前 | `pre_delete` | 删除章节前最后保护 |

## 快照数据结构

```typescript
interface ChapterVersion {
  id: string;              // UUID
  chapterId: string;       // 关联章节
  content: string;         // 完整 Markdown 内容
  contentHash: string;     // 内容的 SHA256 前 16 位（用于去重）
  trigger: 'manual' | 'ai_before_modify' | 'auto_save' | 'pre_delete';
  description: string;     // 人类可读的描述（如 "AI 续写了第3章战斗场面"）
  wordCount: number;       // 快照时的字数
  timestamp: number;       // Unix 毫秒
  sequence: number;        // 该章节的版本序号
}
```

## 去重逻辑

```typescript
// 保存前检查：如果内容 hash 与上一个版本相同，跳过
const shouldSave = lastVersion?.contentHash !== currentHash;
if (!shouldSave) return;

// 自动保存额外检查：如果距离上次保存不到 30 秒且内容未变，跳过
if (trigger === 'auto_save' && Date.now() - lastVersion.timestamp < 30000) return;
```

## 版本回退流程

```
1. 用户打开版本历史面板
2. 选择目标版本
3. 预览 diff（当前 vs 目标版本）
4. 用户确认回退
5. 保存当前版本（作为新快照，防止误操作）← 关键安全措施
6. 将目标版本内容写入编辑器
7. 显示"已回退到 vX，如需撤销请按 Ctrl+Z"
```

## 稀疏化压缩

```
原始: v1 v2 v3 v4 v5 v6 v7 v8 v9 v10 ... v50
                    ↓ 压缩
结果: v1  v2  v3  v4  v5  v6  v7  v8  v9  v10 (最近10个完整)
      v15  v20  v25  v30  v35  v40  v45  v50   (每5个保留1个)
```

压缩后最多保留 `10 + (50-10)/5 = 18` 个版本（vs 原来 50 个）。
