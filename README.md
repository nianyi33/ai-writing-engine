## AI Writing Engine

A full-stack AI-powered writing assistant for web novel authors.

- **7,200+ lines** TypeScript/TSX
- **9 pages**, 11 reusable components, 8 Zustand stores
- **6 AI providers** (OpenAI, Anthropic, DeepSeek, Qwen, GLM, Moonshot) — 18 models
- **13 API endpoints** with SSE streaming & rate limiting
- **PWA + Tauri 2** desktop app (.exe)
- **Built in 3 days** using Vibe Coding methodology
