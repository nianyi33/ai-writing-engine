## 前端模块树

```
src/
├── main.tsx                    # 入口
├── App.tsx                     # 路由 + AppShell
├── theme.ts                    # 暗色主题配置
│
├── pages/
│   ├── Home.tsx                # 首页 — 作品列表
│   ├── Works.tsx               # 作品管理（创建/删除/导入）
│   ├── Editor.tsx              # 主体 — Markdown 编辑器 + AI 侧栏
│   ├── Outline.tsx             # 大纲编辑器 + AI 分析
│   ├── Roles.tsx               # 角色卡片管理
│   ├── RoleChat.tsx            # 角色对话
│   ├── Settings.tsx            # 设置（模型配置/API Key/主题）
│   ├── Stats.tsx               # 写作统计
│   └── Bond.tsx                # 情缘面板
│
├── components/
│   ├── AppShell.tsx            # 全局布局（侧栏 + 顶栏 + 内容区）
│   ├── MarkdownEditor.tsx      # CodeMirror 6 封装
│   ├── MarkdownPreview.tsx     # 实时预览面板
│   ├── AiSidebar.tsx           # AI 功能侧栏（续写/分析/去味）
│   ├── AiChat.tsx              # AI 对话面板
│   ├── AiStreamRenderer.tsx    # 流式文本渲染器
│   ├── OutlineTree.tsx         # 大纲树形编辑器
│   ├── OutlineAssessment.tsx   # AI 大纲评分展示
│   ├── ScoreRadarChart.tsx     # 评分雷达图
│   ├── RoleCard.tsx            # 角色卡片
│   ├── BondGraph.tsx           # 情缘关系图
│   ├── VersionHistory.tsx      # 版本历史列表
│   ├── VersionDiff.tsx         # 版本 diff 对比
│   ├── SettingsForm.tsx        # 设置表单
│   ├── WordCount.tsx           # 实时字数统计
│   └── WorkspaceSelector.tsx   # 作品切换器
│
├── stores/
│   ├── useWorksStore.ts        # 作品列表 + 当前作品
│   ├── useEditorStore.ts       # 编辑器状态 + 内容 + 光标
│   ├── useAiStore.ts           # AI 对话历史 + 流式状态
│   ├── useOutlineStore.ts      # 大纲数据 + 评分
│   ├── useRoleStore.ts         # 角色卡片
│   ├── useBondStore.ts         # 情缘数据
│   ├── useSettingsStore.ts     # 用户配置
│   └── useStatsStore.ts        # 写作统计
│
├── utils/
│   ├── fileSystem.ts           # File System Access API 封装
│   ├── tokenCounter.ts         # Token 计数估算
│   ├── textDiff.ts             # 文本 diff 算法
│   ├── versionManager.ts       # 版本快照 + 回退
│   └── exportUtils.ts          # 导出 EPUB/TXT
│
└── __tests__/                  # 测试文件
```

## 后端模块

```
backend/src/
├── index.ts                    # Express 入口
├── routes/
│   ├── ai.ts                   # /api/ai/* — AI 代理 + 流式
│   ├── files.ts                # /api/files/* — 本地文件 CRUD
│   └── health.ts               # /api/health — 健康检查
├── middleware/
│   ├── rateLimiter.ts          # Rate Limit
│   └── apiKeyGuard.ts          # API Key 验证
├── services/
│   ├── aiRouter.ts             # 多模型路由分发
│   ├── streamForwarder.ts      # SSE 流式转发
│   └── fileService.ts          # 本地文件服务
└── types/
    └── index.ts                # 后端类型定义
```

## 共享模块复用清单

| 现有模块 | 复用方式 | 改动 |
|---------|---------|------|
| `api-client.ts` | 直接复用 | 扩展 `completion()` 支持 system prompt 参数 |
| `stream-client.ts` | 直接复用 | 无 |
| `storage.ts` | Schema 重构 | 新增 works/chapters/versions/roles stores |
| `context-manager.ts` | 扩展 | 从 GameContext → WritingContext 改造 |
| `memory-manager.ts` | 直接复用 | 角色记忆/情节追踪 |
| `config.ts` | 扩展 | 新增写作场景模型配置 |
| `templates.ts` | 改造 | 从游戏模板 → 大纲模板 |
| `modifier.ts` | 改造 | 从游戏修改 → 文字修改（去AI味） |
